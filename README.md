# 📊 Recruitment Hiring Analysis | SQL & Power BI

An end-to-end **Recruitment Hiring Analysis** project built using **MySQL and Power BI** to analyze candidate data, hiring outcomes, recruitment sources, and candidate characteristics.

The project covers **SQL data cleaning, Exploratory Data Analysis (EDA), and interactive Power BI dashboard development**.

---

## 🎯 Project Objective

To analyze recruitment data and identify patterns in **candidate profiles, hiring performance, recruitment sources, and departmental hiring outcomes** to support data-driven recruitment decisions.

---

## 📂 Dataset

* **Raw Records:** 816 candidates
* **Data Type:** Recruitment / Hiring Data
* **Database:** MySQL

### Key Fields

`Candidate_ID` · `Age` · `Gender` · `Department` · `Job_Role` · `Education` · `Experience_Years` · `Application_Date` · `Source` · `Screening_Status` · `Interview_Status` · `Hiring_Status` · `Interview_Score` · `Expected_Salary` · `Time_to_Hire`

---

## 🧹 SQL Data Cleaning & EDA

### Data Cleaning

* Handled missing and inconsistent values
* Standardized categorical data
* Validated date and numerical fields
* Checked duplicates and data quality
* Prepared cleaned data for analysis

### Exploratory Data Analysis

Analyzed:

* Candidate demographics
* Education and experience
* Department and job roles
* Recruitment sources
* Hiring, rejection and pending status
* Interview performance
* Expected salary
* Time to hire

---

## 📊 Power BI Dashboard

The Power BI dashboard contains **3 analytical pages**:

### 1. Recruitment Overview

* Total Applicants
* Hired / Rejected / Pending candidates
* Hiring performance
* Recruitment trends
* Department analysis

### 2. Candidate Analysis

* Age and gender distribution
* Education
* Experience
* Department
* Job-role analysis
* Interview performance

### 3. Source & Hiring Performance

* Applications by recruitment source
* Source-wise hiring performance
* Hiring status comparison
* Department-wise hiring analysis
